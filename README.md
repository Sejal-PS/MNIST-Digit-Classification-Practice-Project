# MNIST-Digit-Classification-Practice-Project
Project demonstrating MNIST digit classification
A beginner-friendly practice project using **TensorFlow 2.x** and **Keras** to classify handwritten digits (0-9).

## Overview
This repository contains a Jupyter Notebook that implements a basic feed-forward neural network. It achieves over **97% accuracy** on the MNIST test set in just 5 training epochs.

## Key Features
- **Data Preprocessing:** Normalization and flattening of image arrays.
- **Model Architecture:** A Sequential model with a Dense hidden layer (ReLU) and an output layer (Softmax).
- **Optimization:** Uses the Adam optimizer and Sparse Categorical Crossentropy loss.

## Requirements
- Python 3.x
- TensorFlow 2.x
- Matplotlib (optional, for visualizations)

## How to Use
1. Clone the repository.
2. Install dependencies: `pip install tensorflow matplotlib`.
3. Run the notebook or script to train and evaluate the model.
